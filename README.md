# Portfolio Marcel Assogba

Portfolio professionnel responsive utilisant Bootstrap 5.

## Structure du Projet

```
PORTOFOLIO VF/
├── css/
│   └── style.css
├── images/
├── index.html
└── README.md
```

## Technologies Utilisées

- HTML5
- CSS3
- Bootstrap 5.3.0
- Font Awesome 6.0.0

## Installation

1. Clonez ce dépôt
2. Ouvrez `index.html` dans votre navigateur

## Développement

Pour modifier le site :
- Le fichier principal est `index.html`
- Les styles personnalisés sont dans `css/style.css`
- Ajoutez vos images dans le dossier `images/`
